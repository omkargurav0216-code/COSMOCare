# COSMOCare
### AI-Powered Astronaut Health Monitoring & Risk Assessment System

COSMOCare is an AI-powered astronaut health monitoring and risk assessment system developed as part of the **NASA Space Apps Challenge 2026**.

Designed to support astronaut well-being during long-duration space missions, COSMOCare leverages machine learning, anomaly detection, explainable risk assessment, and an AI-powered health assistant to transform health data into actionable insights.

## Technology Stack

| Component | Technologies |
|---|---|
| Frontend | React, Vite, JavaScript, Tailwind CSS |
| Data Visualization | Recharts |
| Backend | Python, FastAPI |
| Database | SQLite / PostgreSQL |
| Machine Learning | Pandas, NumPy, Scikit-learn |
| Anomaly Detection | Isolation Forest |
| AI Assistant | LLM API |
| Version Control | Git, GitHub |
